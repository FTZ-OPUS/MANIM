# MANIM — 漂亮的雷达图动画

基于 [Manim](https://www.manim.community/) 的六维雷达图动画项目。

> **未来计划**：本项目将逐步封装为一个可复用的 Manim 雷达图插件，发布到 **PyPI**，届时只需 `pip install` 即可在任意 Manim 项目中调用六维雷达图动画。敬请期待。

---

## 两个版本对比

### 雷达图 1.0 — 复刻版

文件：`雷达图1.0.py`  
类名：`RadarRemake`  
定位：依据原片 120.6s / 1280×720@30fps 逐帧逆向复刻。

- 黑底星空粒子背景（46 颗三层光晕星点）
- 六维雷达：理论 / 实践 / 群众 / 品德 / 国际 / 历史
- 23 个人物分段，颜色 morph + 数值滚动
- 大转场（放大+压暗）、黑场间隔、故障闪入 + 橙蓝描边高亮

### 雷达图 2.0 — 美学升级版

文件：`雷达图2.0.py`  
类名：`RadarV2`  
定位：在 1.0 基础上的全面视觉升级——**色彩更丰富、效果更高级**。

2.0 相比 1.0 的具体升级：

| 模块 | 1.0 | 2.0 |
|------|-----|-----|
| **背景** | 纯黑底 + 46 颗星点 | 深空蓝渐变（中心辉光 + 四角暗角）+ 8 团随主色呼吸的星云 + 64 颗星点（含彩色星） |
| **网格** | 灰色多边形环 + 灰色辐条 | 冷色高亮环（外环 0.95 / 内环 0.5）+ **六轴各自彩色辐条** + 网格辉光底层 + 顶部刻度数字 |
| **雷达体** | 单色填充 + 单层辉光 + 白色描边 | 主色填充 0.45 + **内芯提亮** + 双层辉光 + **六轴六色渐变彩虹描边** + 顶点四层光点（光晕+实心+白点） |
| **转场** | 颜色 morph + 数值跳变后滚动 | **冲击波圆环**（扩散/内缩）+ 颜色 morph + 数值先沉后滚；大转场 zoom+压暗；黑场后**故障闪入（RGB 分离 + 故障条）** |
| **数字** | 分段替换文本 | **滚轮式（odometer）连续滚动**，随 ValueTracker 丝滑跟随 |
| **扫描** | 无 | **雷达扇形扫光 5.5s/圈**，颜色跟随主色 |
| **标题** | 无 | 顶部渐变标题「六维能力 · 雷达图鉴」 |

一句话总结：**1.0 是「能跑」，2.0 是「好看」——多了大量色彩层次、辉光特效和转场细节。**

## 不等式雷达图鉴

目录：`不等式雷达图源码/`  
类名：`IneqRadar`  

左侧六维雷达随卡 morph，右侧不等式名称 + LaTeX 公式 + 一句话注解，共 25 条经典不等式。

| 文件 | 说明 |
|------|------|
| `ineq_radar.py` | 主场景（左雷达右公式混剪，1 秒/卡） |
| `ir_data.py` | 25 条不等式数据（名称 / LaTeX / 注解 / 六维评分） |
| `verify_ineq.py` | 25 条不等式的 numpy 数值验证脚本（25/25 PASS） |

六维评分维度：考试频率 / 竞赛热度 / 数学美感 / 应用广度 / 初等亲和 / 推广深度。

## 环境依赖

```bash
pip install manim numpy
```

还需要系统安装 [FFmpeg](https://ffmpeg.org/) 和 LaTeX（渲染公式用）。

## 运行方式

```bash
# 渲染雷达图 2.0（高质量）
manim -pqh 雷达图2.0.py RadarV2

# 渲染雷达图 1.0 复刻版
manim -pqh 雷达图1.0.py RadarRemake

# 渲染不等式雷达图鉴
cd 不等式雷达图源码
manim -pqh ineq_radar.py IneqRadar

# 运行不等式数值验证
python verify_ineq.py
```
