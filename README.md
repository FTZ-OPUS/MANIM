# MANIM — 漂亮的雷达图动画

基于 [Manim](https://www.manim.community/) 的六维雷达图动画项目。

## 项目内容

### 源码

| 文件 | 说明 |
|------|------|
| `雷达图1.0.py` | 雷达图复刻版（120.6s / 23 段 / 黑底星空粒子） |
| `雷达图2.0.py` | 雷达图 2.0 美学升级版（深空蓝渐变 + 彩虹描边 + 扫描扇面 + 滚轮数字） |
| `不等式雷达图源码/ineq_radar.py` | 不等式天花板雷达图鉴主场景（左雷达右公式混剪） |
| `不等式雷达图源码/ir_data.py` | 25 条不等式数据（名称/LaTeX/注解/六维评分） |
| `不等式雷达图源码/verify_ineq.py` | 25 条不等式的 numpy 数值验证脚本 |

### 案例视频

仓库中包含以下渲染好的案例视频（.mp4）：

- `雷达图2.0.mp4` — 雷达图 2.0 完整版
- `雷达图复刻.mp4` — 雷达图 1.0 复刻版
- `不等式天花板雷达图鉴.mp4` — 不等式主题雷达图鉴

## 环境依赖

```bash
pip install manim numpy
```

还需要系统安装 [FFmpeg](https://ffmpeg.org/) 和 LaTeX（渲染公式用）。

## 运行方式

```bash
# 渲染雷达图 2.0（高质量）
manim -pqh 雷达图2.0.py RadarV2

# 渲染雷达图 1.0 复刻版
manim -pqh 雷达图1.0.py RadarRemake

# 渲染不等式雷达图鉴
cd 不等式雷达图源码
manim -pqh ineq_radar.py IneqRadar

# 运行不等式数值验证
python verify_ineq.py
```

## 六维评分维度

- **不等式雷达图鉴**：考试频率 / 竞赛热度 / 数学美感 / 应用广度 / 初等亲和 / 推广深度
